# Графік Żabka · Kraków

Веб-застосунок (телефон і комп'ютер) для графіку змін, обліку робочого часу й доставок на трьох локаціях. Інтерфейс українською, з перемикачем на польську.

## Запуск

Потрібен Node.js 22.13 або новіший.

```bash
npm install
npm start            # http://localhost:3000
```

`npm run demo` — те саме, але з демо-графіком на 3 тижні (лише для ознайомлення, на порожній базі).

Під час першого запуску створюються локації, адміністратори й працівники. Початковий пароль для всіх: `zabka2026` (можна змінити змінною `INITIAL_PASSWORD`). **Одразу змініть паролі** в «Налаштуваннях».

### Змінні середовища
- `PORT` — порт (типово 3000)
- `DB_PATH` — файл бази SQLite (типово `data/zabka.db`) — **робіть резервні копії цього файлу**
- `TELEGRAM_BOT_TOKEN` — токен бота від @BotFather; без нього сповіщення лише в застосунку
- `INITIAL_PASSWORD` — пароль для початкових акаунтів

### Telegram
1. Створіть бота в @BotFather і вкажіть токен у `TELEGRAM_BOT_TOKEN`.
2. Кожен користувач: «Налаштування» → «Прив'язати Telegram» → «Start» у боті.

### Експорт ODS
PDF і XLSX працюють завжди. Для ODS на сервері потрібен LibreOffice (`soffice`) — у Dockerfile він уже є.

### Docker
```bash
docker build -t zabka-grafik .
docker run -d -p 3000:3000 -v zabka-data:/data -e TELEGRAM_BOT_TOKEN=... zabka-grafik
```
Для доступу з телефонів потрібен HTTPS: поставте застосунок за reverse proxy (Caddy / nginx) або на хостинг на кшталт Railway / Render / Fly.io з постійним диском.

## Ролі
- **Адміністратори** (усі однакові): повний доступ до всіх локацій, ставок, графіків, диспозиції, запитів, премій/штрафів, звітів, закриття й відкриття місяця, працівників і локацій. Закріплення за локацією визначає лише, звідки за замовчуванням приходять запити й сповіщення (у «Налаштуваннях» можна увімкнути й інші локації).
- **Працівники**: свій графік, свої години й суми, запити, нотатки, «Моя доступність».

## Як це працює (коротко)
- **Графік**: адміністратор заповнює тиждень (1-ша / 2-га зміна, доставки, докладка 18:00 — лише там, де її ввімкнено), «⏱» — нестандартний час; кінець 1-ї зміни автоматично стає початком 2-ї. Порушення правил **блокують збереження**.
- **Облік**: опублікована зміна зараховується автоматично після закінчення (час — Europe/Warsaw). Працівник не може змінити свій час — лише надіслати запит.
- **Запити**: додатковий час, заміна, затримка пересменки (зсуває обидві зміни), пішов раніше / не вийшов, виправлення палет, навчання. Підтвердження перевіряє ті самі правила й показує, з ким конфлікт.
- **Факт / план**: підтверджені запити й корекції «✎ Факт» змінюють лише факт; план лишається для тижневого звіту.
- **Палети**: 120 + (палети − 1) × 80 zł за кожну доставку.
- **Диспозиція**: працівник до дедлайну (типово четвер 20:00) відмічає кожен день наступного тижня; після дедлайну — тільки через запит. Адміністратор бачить кольорову таблицю, може копіювати тиждень, заповнювати весь тиждень і виправляти. У графіку список працівників сортується за доступністю, а постановка того, хто не може, вимагає підтвердження.
- **Закриття місяця** блокує зміни; відкрити знову може будь-який адміністратор. Уся історія — в «Історія змін».
